# Portifólio
Para rodar o portifólio localmente, será necessário primeiro realizar a instalação das dependencias do projeto. Para isso basta realizar o seguinte comando:

```
npm install
```

Após isso basta executar o projeto com:

```
npm run dev
```

Caso queira acessar o projeto online, basta seguir pelo seguinte link: [Portifólio](https://portifolio-blue-ten-97.vercel.app)

# Sobre os projetos

Resolvi neste portifólio mostrar alguns projetos que mais tive trabalho em realizar, começando com o projeto sobre micro front-end, onde o intuito era entender a separar um projeto em varias partes e posteriormente unilas em um unico ponto, para assim facilitar o trabalho de uma equipe que mexe em várias partes de um projeto em simuntaneo. <br /><br />

Como segundo projeto, está um focado na funcionalidade de PWA, onde tinhamos que realizar a configuração de um PWA em um site o fazendo funcionar como uma aplicação e de forma offline. <br /><br />

O ultimo projeto apresentado se trata de um exercicio sobre Pipelines (ci/cd), onde deveriamos configurar a pipeline para executar testes unitários e o deploy de forma automática.
